# Siphon Spec v0.9

Expands `min_time` and `max_time` to also accept plain time-of-day strings (`HH:MM` and `HH:MM:SS`), not just ISO 8601 datetimes. No new fields or operators — the input range of two existing operators widens.

## Overview

`reduce` collapses an array path into a single value by applying a named aggregation operator. It is mutually exclusive with `collect` — where `collect: true` returns every match, `reduce` returns exactly one computed result.

```python
spec = {
    "extract": {
        "earliest_slot": {
            "path": "$.data.items[*].availability_from_date_time",
            "reduce": "min_time",
        },
        "latest_slot": {
            "path": "$.data.items[*].availability_to_date_time",
            "reduce": "max_time",
        },
    }
}
```

---

## FieldSpec Schema

```python
@dataclass
class FieldSpec:
    path: str                         # Required: JSONPath expression
    where: dict | None = None         # Optional: filter conditions
    select: dict | None = None        # Optional: field projection/renaming
    collect: bool = False             # Optional: return all matches
    reduce: str | dict | None = None  # Optional: aggregation operator
```

`reduce` accepts either a plain operator name string, or a dict with `"op"` and operator-specific options (currently only `concat` uses this):

```python
# plain string
"reduce": "sum"

# dict (used for concat with a custom separator)
"reduce": {"op": "concat", "sep": " | "}
```

## Reduce Operators

### Time-of-day: `min_time` / `max_time`

Compares only the `HH:MM:SS` portion. Accepts either an ISO 8601 datetime (`2026-04-11T13:30:00+04:00`) or a plain time string (`13:30`, `13:30:00`). **Date and timezone are ignored**, so items from different dates/zones are compared purely by their time-of-day.

The two input forms can be mixed within a single path — each value is parsed independently.

```python
# ISO 8601 datetime form
data = {
    "items": [
        {"slot": "2026-04-11T13:30:00+04:00"},
        {"slot": "2026-04-12T09:15:00+04:00"},  # earliest time of day
        {"slot": "2026-04-13T22:00:00+04:00"},  # latest time of day
    ]
}

spec = {
    "extract": {
        "first_slot_of_day": {"path": "$.items[*].slot", "reduce": "min_time"},
        "last_slot_of_day":  {"path": "$.items[*].slot", "reduce": "max_time"},
    }
}

# {
#   "first_slot_of_day": "2026-04-12T09:15:00+04:00",
#   "last_slot_of_day":  "2026-04-13T22:00:00+04:00"
# }
```

```python
# Plain HH:MM / HH:MM:SS form (new in v0.9)
data = {
    "items": [
        {"t": "13:30"},
        {"t": "09:15"},   # earliest
        {"t": "22:00"},   # latest
    ]
}

spec = {
    "extract": {
        "opening": {"path": "$.items[*].t", "reduce": "min_time"},
        "closing": {"path": "$.items[*].t", "reduce": "max_time"},
    }
}

# {"opening": "09:15", "closing": "22:00"}
```

**Use case**: schedules or opening hours that publish a bare `HH:MM` without a date wrapper, alongside availability windows that include full ISO datetimes.

### Calendar date: `min_date` / `max_date`

Compares only the `YYYY-MM-DD` portion of an ISO 8601 datetime or date string. **Time and timezone are ignored.**

```python
data = {
    "bookings": [
        {"created": "2026-03-15T10:00:00+00:00"},
        {"created": "2026-01-01T23:59:00+00:00"},  # earliest date
        {"created": "2026-06-30T08:00:00+00:00"},  # latest date
    ]
}

spec = {
    "extract": {
        "oldest_booking": {"path": "$.bookings[*].created", "reduce": "min_date"},
        "newest_booking": {"path": "$.bookings[*].created", "reduce": "max_date"},
    }
}
```

---

### Full datetime: `min_datetime` / `max_datetime`

Compares the **full datetime including timezone offset**. Items with different timezone offsets are normalised before comparison, so `10:00+05:30` (04:30 UTC) correctly sorts before `12:00+04:00` (08:00 UTC).

```python
data = {
    "events": [
        {"dt": "2026-04-11T10:00:00+05:30"},  # 04:30 UTC — earliest
        {"dt": "2026-04-11T12:00:00+04:00"},  # 08:00 UTC — latest
        {"dt": "2026-04-11T01:00:00+00:00"},  # 01:00 UTC
    ]
}

spec = {
    "extract": {
        "first_event": {"path": "$.events[*].dt", "reduce": "min_datetime"},
        "last_event":  {"path": "$.events[*].dt", "reduce": "max_datetime"},
    }
}
```

**When to use `min_datetime` vs `min_date` vs `min_time`:**

| Operator | Ignores | Accepts | Use when |
|---|---|---|---|
| `min_time` / `max_time` | date + timezone | ISO 8601 datetime **or** plain `HH:MM` / `HH:MM:SS` | "what's the earliest opening hour?" |
| `min_date` / `max_date` | time + timezone | ISO 8601 datetime or date | "what's the first day with availability?" |
| `min_datetime` / `max_datetime` | nothing | ISO 8601 datetime | "what's the absolute earliest moment?" |

---

### Numeric: `min_int` / `max_int` / `sum`

Standard numeric aggregations. Work for both integers and floats.

```python
spec = {
    "extract": {
        "cheapest":    {"path": "$.products[*].price", "reduce": "min_int"},
        "priciest":    {"path": "$.products[*].price", "reduce": "max_int"},
        "total_stock": {"path": "$.products[*].stock", "reduce": "sum"},
    }
}
```

---

### Count

Returns the number of non-null values matched by the path. Unlike all other operators, `count` returns `0` (not `None`) for an empty array.

```python
spec = {
    "extract": {
        "total_items": {"path": "$.data.items[*].id", "reduce": "count"},
    }
}
```

---

### Positional: `first` / `last`

Returns the first or last non-null value in array traversal order.

```python
spec = {
    "extract": {
        "first_name": {"path": "$.users[*].name", "reduce": "first"},
        "last_name":  {"path": "$.users[*].name", "reduce": "last"},
    }
}
```

---

### Concat

Joins all values as strings with a separator. Default separator is `", "`.

```python
# Default separator
spec = {"extract": {"tag_list": {"path": "$.tags[*].name", "reduce": "concat"}}}
# {"tag_list": "python, api, data"}

# Custom separator — use the dict form
spec = {
    "extract": {
        "tag_list": {
            "path": "$.tags[*].name",
            "reduce": {"op": "concat", "sep": " | "},
        }
    }
}
# {"tag_list": "python | api | data"}
```

---

### Distinct

Deduplicates values, preserving first-seen order.

```python
spec = {
    "extract": {
        "categories": {"path": "$.events[*].category", "reduce": "distinct"},
    }
}
```

## Behavior Reference

### Return values for empty arrays

| Operator | Empty array returns |
|---|---|
| All `min_*` / `max_*` | `None` |
| `sum` | `None` |
| `first` / `last` | `None` |
| `concat` | `None` |
| `distinct` | `None` |
| `count` | `0` |

### Input parsing for `min_time` / `max_time`

A value is treated as a plain time-of-day if it contains no `T` separator. Otherwise it is parsed as an ISO 8601 datetime and the time component is extracted (timezone stripped). Both forms reduce to an `(H, M, S)` comparison key.

| Input | Parsed as |
|---|---|
| `"09:15"` | `(9, 15, 0)` |
| `"09:15:30"` | `(9, 15, 30)` |
| `"2026-04-12T09:15:00+04:00"` | `(9, 15, 0)` |
| `"2026-04-12T09:15:00Z"` | `(9, 15, 0)` |

### Interaction with `where`

`where` filters first, then `reduce` aggregates the matching values:

```python
spec = {
    "extract": {
        "active_total": {
            "path": "$.items[*].price",
            "where": {"status": "active"},
            "reduce": "sum",
        }
    }
}
```

### Interaction with `collect`

`reduce` and `collect` are mutually exclusive. If both are set, `reduce` takes precedence.

## Examples

See [history/v0.8.md](history/v0.8.md) for the audit-log and availability-window examples introduced with `reduce`. They continue to work unchanged in v0.9.

### Opening hours from a plain-time API

```python
data = {
    "venues": [
        {"name": "Café", "opens": "07:00", "closes": "22:30"},
        {"name": "Bar",  "opens": "17:00", "closes": "02:00"},
        {"name": "Shop", "opens": "09:00", "closes": "18:00"},
    ]
}

spec = {
    "extract": {
        "earliest_open": {"path": "$.venues[*].opens",  "reduce": "min_time"},
        "latest_close":  {"path": "$.venues[*].closes", "reduce": "max_time"},
    }
}

# {"earliest_open": "07:00", "latest_close": "22:30"}
```

## Changes from v0.8

### Changed

- `min_time` / `max_time` now accept plain `HH:MM` and `HH:MM:SS` strings in addition to ISO 8601 datetimes. Values without a `T` separator are parsed as bare time-of-day.

### No breaking changes

All v0.8 specs are valid v0.9 specs. ISO 8601 inputs continue to parse identically.
