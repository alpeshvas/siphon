# Siphon Spec v0.8

Introduces `reduce` — a declarative aggregation operator for the flat extraction API. Instead of collecting all values and post-processing in application code, you can express aggregations (min, max, sum, count, etc.) directly in the spec.

## Overview

`reduce` collapses an array path into a single value by applying a named aggregation operator. It is mutually exclusive with `collect` — where `collect: true` returns every match, `reduce` returns exactly one computed result.

```python
spec = {
    "extract": {
        "earliest_slot": {
            "path": "$.data.items[*].availability_from_date_time",
            "reduce": "min_time",
        },
        "latest_slot": {
            "path": "$.data.items[*].availability_to_date_time",
            "reduce": "max_time",
        },
    }
}
```

---

## FieldSpec Schema

```python
@dataclass
class FieldSpec:
    path: str                         # Required: JSONPath expression
    where: dict | None = None         # Optional: filter conditions
    select: dict | None = None        # Optional: field projection/renaming
    collect: bool = False             # Optional: return all matches
    reduce: str | dict | None = None  # Optional: aggregation operator
```

`reduce` accepts either a plain operator name string, or a dict with `"op"` and operator-specific options (currently only `concat` uses this):

```python
# plain string
"reduce": "sum"

# dict (used for concat with a custom separator)
"reduce": {"op": "concat", "sep": " | "}
```

## Reduce Operators

### Time-of-day: `min_time` / `max_time`

Compares only the `HH:MM:SS` portion of ISO 8601 datetime strings. **Date and timezone are ignored**, so items from different dates are compared purely by their time-of-day.

```python
data = {
    "items": [
        {"slot": "2026-04-11T13:30:00+04:00"},
        {"slot": "2026-04-12T09:15:00+04:00"},  # earliest time of day
        {"slot": "2026-04-13T22:00:00+04:00"},  # latest time of day
    ]
}

spec = {
    "extract": {
        "first_slot_of_day": {"path": "$.items[*].slot", "reduce": "min_time"},
        "last_slot_of_day":  {"path": "$.items[*].slot", "reduce": "max_time"},
    }
}

# {
#   "first_slot_of_day": "2026-04-12T09:15:00+04:00",
#   "last_slot_of_day":  "2026-04-13T22:00:00+04:00"
# }
```

**Use case**: availability windows where you want the earliest check-in or latest check-out time across multiple dates.

---

### Calendar date: `min_date` / `max_date`

Compares only the `YYYY-MM-DD` portion. **Time and timezone are ignored.**

```python
data = {
    "bookings": [
        {"created": "2026-03-15T10:00:00+00:00"},
        {"created": "2026-01-01T23:59:00+00:00"},  # earliest date
        {"created": "2026-06-30T08:00:00+00:00"},  # latest date
    ]
}

spec = {
    "extract": {
        "oldest_booking": {"path": "$.bookings[*].created", "reduce": "min_date"},
        "newest_booking": {"path": "$.bookings[*].created", "reduce": "max_date"},
    }
}

# {
#   "oldest_booking": "2026-01-01T23:59:00+00:00",
#   "newest_booking": "2026-06-30T08:00:00+00:00"
# }
```

---

### Full datetime: `min_datetime` / `max_datetime`

Compares the **full datetime including timezone offset**. Items with different timezone offsets are normalised before comparison, so `10:00+05:30` (04:30 UTC) correctly sorts before `12:00+04:00` (08:00 UTC).

```python
data = {
    "events": [
        {"dt": "2026-04-11T10:00:00+05:30"},  # 04:30 UTC — earliest
        {"dt": "2026-04-11T12:00:00+04:00"},  # 08:00 UTC — latest
        {"dt": "2026-04-11T01:00:00+00:00"},  # 01:00 UTC
    ]
}

spec = {
    "extract": {
        "first_event": {"path": "$.events[*].dt", "reduce": "min_datetime"},
        "last_event":  {"path": "$.events[*].dt", "reduce": "max_datetime"},
    }
}

# {
#   "first_event": "2026-04-11T01:00:00+00:00",
#   "last_event":  "2026-04-11T12:00:00+04:00"
# }
```

**When to use `min_datetime` vs `min_date` vs `min_time`:**

| Operator | Ignores | Use when |
|---|---|---|
| `min_time` / `max_time` | date + timezone | "what's the earliest opening hour across all days?" |
| `min_date` / `max_date` | time + timezone | "what's the first day with availability?" |
| `min_datetime` / `max_datetime` | nothing | "what's the absolute earliest moment?" |

### Numeric: `min_int` / `max_int` / `sum`

Standard numeric aggregations. Work for both integers and floats.

```python
data = {
    "products": [
        {"sku": "A", "price": 19.99, "stock": 42},
        {"sku": "B", "price": 5.50,  "stock": 7},
        {"sku": "C", "price": 150.0, "stock": 99},
    ]
}

spec = {
    "extract": {
        "cheapest":    {"path": "$.products[*].price", "reduce": "min_int"},
        "priciest":    {"path": "$.products[*].price", "reduce": "max_int"},
        "total_stock": {"path": "$.products[*].stock", "reduce": "sum"},
    }
}

# {"cheapest": 5.5, "priciest": 150.0, "total_stock": 148}
```

### Count

Returns the number of non-null values matched by the path. Unlike all other operators, `count` returns `0` (not `None`) for an empty array.

```python
spec = {
    "extract": {
        "total_items": {"path": "$.data.items[*].id", "reduce": "count"},
    }
}
```

`count` can be combined with `where` to count filtered results — but note that `where` filtering happens in the normal collect loop, not in the reduce path. For filtered counts, use `collect: true` and count in application code, or use the `query`/`pipeline` API.

---

### Positional: `first` / `last`

Returns the first or last non-null value in array traversal order.

```python
spec = {
    "extract": {
        "first_name": {"path": "$.users[*].name", "reduce": "first"},
        "last_name":  {"path": "$.users[*].name", "reduce": "last"},
    }
}
```

`first` without `reduce` is equivalent to the default behaviour (no `collect`, no `reduce`). Use `reduce: "first"` for explicitness, or `reduce: "last"` when you need the final item.

---

### Concat

Joins all values as strings with a separator. Default separator is `", "`.

```python
data = {"tags": [{"name": "python"}, {"name": "api"}, {"name": "data"}]}

# Default separator
spec = {"extract": {"tag_list": {"path": "$.tags[*].name", "reduce": "concat"}}}
# {"tag_list": "python, api, data"}

# Custom separator — use the dict form
spec = {
    "extract": {
        "tag_list": {
            "path": "$.tags[*].name",
            "reduce": {"op": "concat", "sep": " | "},
        }
    }
}
# {"tag_list": "python | api | data"}
```

---

### Distinct

Deduplicates values, preserving first-seen order.

```python
data = {
    "events": [
        {"category": "sport"},
        {"category": "music"},
        {"category": "sport"},
        {"category": "food"},
        {"category": "music"},
    ]
}

spec = {
    "extract": {
        "categories": {"path": "$.events[*].category", "reduce": "distinct"},
    }
}

# {"categories": ["sport", "music", "food"]}
```

## Behavior Reference

### Return values for empty arrays

| Operator | Empty array returns |
|---|---|
| All `min_*` / `max_*` | `None` |
| `sum` | `None` |
| `first` / `last` | `None` |
| `concat` | `None` |
| `distinct` | `None` |
| `count` | `0` |

### Interaction with `where`

`reduce` and `where` can be combined. `where` filters first, then `reduce` aggregates the matching values:

```python
spec = {
    "extract": {
        "active_total": {
            "path": "$.items[*].price",
            "where": {"status": "active"},
            "reduce": "sum",
        }
    }
}
```

### Interaction with `collect`

`reduce` and `collect` are mutually exclusive. If both are set, `reduce` takes precedence.

## Examples

### Availability window (real-world)

Extract the earliest start time and latest end time across all availability slots, regardless of which date they fall on:

```python
data = {
    "content": {
        "data": {
            "data": {
                "items": [
                    {
                        "availability_from_date_time": "2026-04-11T13:30:00+04:00",
                        "availability_to_date_time":   "2026-04-11T13:45:00+04:00",
                    },
                    {
                        "availability_from_date_time": "2026-04-12T09:15:00+04:00",
                        "availability_to_date_time":   "2026-04-12T22:00:00+04:00",
                    },
                    {
                        "availability_from_date_time": "2026-04-13T14:00:00+04:00",
                        "availability_to_date_time":   "2026-04-13T14:15:00+04:00",
                    },
                ]
            }
        }
    }
}

spec = {
    "extract": {
        "earliest_from_datetime": {
            "path": "$.content.data.data.items[*].availability_from_date_time",
            "reduce": "min_time",
        },
        "latest_to_datetime": {
            "path": "$.content.data.data.items[*].availability_to_date_time",
            "reduce": "max_time",
        },
    }
}

result = process(spec, data)
# {
#   "earliest_from_datetime": "2026-04-12T09:15:00+04:00",
#   "latest_to_datetime":     "2026-04-12T22:00:00+04:00"
# }
```

## Changes from v0.7

### Added

- `reduce` field on `FieldSpec` (`str | dict | None`, default `None`)
- 14 built-in reduce operators:

| Operator | Input type | Description |
|---|---|---|
| `min_time` | ISO 8601 datetime string | Value with earliest time-of-day (ignores date + timezone) |
| `max_time` | ISO 8601 datetime string | Value with latest time-of-day (ignores date + timezone) |
| `min_date` | ISO 8601 datetime/date string | Value with earliest calendar date (ignores time) |
| `max_date` | ISO 8601 datetime/date string | Value with latest calendar date (ignores time) |
| `min_datetime` | ISO 8601 datetime string | Chronologically earliest value (timezone-normalised) |
| `max_datetime` | ISO 8601 datetime string | Chronologically latest value (timezone-normalised) |
| `min_int` | number | Minimum numeric value |
| `max_int` | number | Maximum numeric value |
| `sum` | number | Sum of all values |
| `count` | any | Count of non-null values (returns `0` for empty) |
| `first` | any | First value in traversal order |
| `last` | any | Last value in traversal order |
| `concat` | string | Values joined by separator (default `", "`) |
| `distinct` | any | Deduplicated list, first-seen order |

### No breaking changes

All v0.7 specs are valid v0.8 specs. `reduce` is opt-in.
